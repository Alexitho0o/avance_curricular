# Regla de componentes (borrador)

El componente 1 se construirá desde la regla oficial de Retención de 1er año. El componente 2 reutiliza sin duplicar la regla intertrimestral existente. El componente 3 solo se propone si se verifica un enlace RUT–MRUN; de lo contrario permanece pendiente. El componente 4 genera salidas después de validar los componentes anteriores.
