# Criterios de versionado - IRE 2026

- Las fuentes originales no se modifican.
- Los derivados se crean en carpetas de trabajo o resultados.
- Los archivos reproducibles pueden sobrescribirse si el comando o script permite regenerarlos.
- Los archivos usados para decisiones, auditorias, cargas o dictamenes deben conservarse.
- El historico manual se guarda solo cuando exista decision explicita o justificacion del hito.
- Toda eliminacion, reemplazo, movimiento o congelamiento debe quedar registrado en manifiesto.
- No se copia al Escritorio salvo solicitud explicita del usuario.
- Si una vez se solicita copia al Escritorio para un tipo de entregable, esa regla queda registrada para futuras entregas de ese tipo.
