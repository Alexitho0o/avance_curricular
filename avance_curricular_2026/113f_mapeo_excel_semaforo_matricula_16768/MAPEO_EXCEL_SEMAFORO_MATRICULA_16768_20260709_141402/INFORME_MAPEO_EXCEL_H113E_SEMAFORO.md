# H113F — Mapeo semáforo Excel H113E

## Dictamen

REGENERAR_CON_COLOR_FISICO_DIRECTO

## Problemas detectados

- Hay valores 100% exactos que deben formatearse como 100%, no como 100,0%.

## Recomendación

- No depender de formato condicional con fórmulas.
- Aplicar color físico directo por celda en columnas de porcentaje/tasa.
- Usar rojo para 5% más bajo.
- Usar amarillo para valores intermedios.
- Usar verde para 5% más alto.
- Formatear 100% exacto como `0%`.
- Formatear porcentajes distintos de 100% como `0.0%`.
