## Regla de precedencia

1. Para periodos 2010–2026, el Excel histórico comparativo SIES constituye la referencia principal para contrastar la historia institucional del código 162.
2. El PDF de glosario constituye la referencia para interpretar campos, codificaciones y unidades del histórico.
3. Los archivos operativos institucionales en OneDrive se preservan como evidencia secundaria del proceso de envío.
4. Si una métrica o registro de una fuente institucional no coincide con el histórico SIES prioritario, se debe generar una alerta documentada.
5. No se debe sobrescribir, modificar ni “ajustar” ninguna fuente sin registrar:
   - archivo origen;
   - clave comparada;
   - periodo;
   - diferencia detectada;
   - criterio del glosario aplicable;
   - resolución responsable.
6. El archivo congelado de oferta académica 2027 se mantiene como fuente institucional de proceso actual; queda fuera del rango 2010–2026 y deberá contrastarse cuando exista un histórico SIES oficial para 2027.
