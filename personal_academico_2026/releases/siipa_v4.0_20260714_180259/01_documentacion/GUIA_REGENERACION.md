# Guía de Regeneración

Desde la raíz del repositorio:

```bash
python personal_academico_2026/scripts/generar_siipa_kpi.py --diagnostico
python personal_academico_2026/scripts/generar_siipa_kpi.py --exportar --output /ruta/controlada/PERSONAL_ACADEMICO_SIIPA_KPI_v4.0.xlsx
```

No usar Exceles previos ni almacenamiento externo como fuente.
